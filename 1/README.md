# UniSync AI - ระบบสรุปเลกเชอร์ 15 นาที & จัดการงานกลุ่มไร้ความขัดแย้ง

> แพลตฟอร์มเพื่อนคู่คิดช่วงสอบสำหรับนักศึกษายุคใหม่: แปลงสไลด์เรียนเป็นชีทสรุป 15 นาที, พากย์เสียงติวเตอร์ออกลำโพงจริง, ซ้อมทำข้อสอบจำลอง และระบบบริหารงานกลุ่มด้วยรหัสชวนเพื่อนพร้อมส่งอีเมลแจ้งเตือนอัตโนมัติ

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. ระบบจัดการงานกลุ่มด้วยรหัส (Invite Code & Fair Workload)
* **สร้างกลุ่มง่ายใน 1 คลิก**: ระบบสุ่มสร้างรหัสชวนเพื่อน เช่น `SYNC-3020`
* **เพื่อนเข้าร่วมด้วยรหัส**: สมาชิกกรอกรหัสและเข้าร่วมกลุ่มได้ทันที พร้อมระบุชื่อและอีเมลจริง
* **กระจายภาระงานเท่าเทียม (Fair Workload Balance)**: คำนวณ % ปริมาณงานของสมาชิกแต่ละคนเพื่อป้องกันปัญหา Free-rider
* **กระดาน Kanban ติดตามงาน**: To Do -> In Progress -> Review -> Done

### 2. ส่งอีเมลเตือนเพื่อนร่วมทีมสุภาพ (Polite Email Nudge)
* **1-Click Gmail Web Compose**: เปิดหน้าร่างอีเมลใน Gmail พร้อมใส่ผู้รับ, หัวข้อ และเนื้อหาสุภาพให้เสร็จสรรพ
* **รองรับ 3 สไตล์ข้อความ**:
  * 🌸 สุภาพ เป็นกันเอง (Friendly)
  * ⚡ กระชับ ทางการ (Direct / Formal)
  * ⏳ ด่วนก่อนเดดไลน์ 24 ชม. (Urgent Countdown)
* **บันทึกประวัติการเตือน**: ระบบจดจำเวลาเตือนล่าสุดให้ทั้งทีมรับรู้ร่วมกัน

### 3. สรุปสไลด์เลกเชอร์ 15 นาที (AI Quick Recap)
* รองรับการอัปโหลดไฟล์ PDF ภาษาไทยและอังกฤษ สกัดเนื้อหาด้วย Client-side PDF.js
* สรุปประเด็นสำคัญ, จุดระวังข้อสอบหลอก (Exam Traps), และสูตร/นิยามสำคัญ
* ทำงานได้ทันทีโดยไม่ต้องเชื่อมต่อ API ภายนอก หรือใส่ Gemini API Key เสริมได้

### 4. พากย์เสียงติวเตอร์ออกลำโพงจริง (Web Speech Synthesis)
* สังเคราะห์เสียงบรรยายสรุปเนื้อหาเป็นภาษาไทย
* ปรับความเร็วเสียงพูดได้ (0.9x, 1.0x, 1.25x) พร้อมปุ่มหยุดและฟังซ้ำ

### 5. ข้อสอบจำลองและเฉลยละเอียด (Mock Exam & Explanations)
* แบบทดสอบปรนัยพร้อมคำอธิบายเฉลยทุกข้อ อ้างอิงหน้าสไลด์

## 🚀 วิธีเปิดใช้งานในเครื่อง (Local Development)

### ข้อกำหนดเบื้องต้น
* [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป)

### ขั้นตอนการรัน
```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. เริ่มเซิร์ฟเวอร์สำหรับพัฒนา
npm run dev
```
หรือดับเบิลคลิกไฟล์ `start-dev.bat` บน Windows

## 🌐 การ Deploy ขึ้น GitHub Pages

โปรเจกต์นี้ตั้งค่า GitHub Actions ไว้อัตโนมัติใน `.github/workflows/deploy.yml` แล้ว:

1. สร้าง Repository ใหม่บน [GitHub](https://github.com/new)
2. อัปโหลดโค้ดขึ้น Repository
3. ไปที่แท็บ **Settings** -> **Pages**
4. ที่หัวข้อ **Build and deployment** -> **Source** ให้เลือก **GitHub Actions**
5. รอประมาณ 1-2 นาที คุณจะได้รับ URL เว็บไซต์ เช่น `https://<your-username>.github.io/<repo-name>/` พร้อมส่งให้เพื่อนใช้งานได้ทันที!
